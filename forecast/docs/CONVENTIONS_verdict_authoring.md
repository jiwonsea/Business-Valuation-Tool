## P-1. 반증조건(RC) 등록 규격 — 3요소 필수

판정 트리거로 등록하는 반증조건은 다음 3요소를 **등록 시점에** 모두 갖춰야 한다:

1. **관측원** — 어느 공시의 어느 절/라인에서 관측되는가 (프린트 PR / 10-Q / 기타, 절 단위로 특정).
2. **수치 임계값 (사전등록)** — 발화/미발화를 기계적으로 가르는 숫자. 감소율 또는 절대금액.
   임계값을 정당화할 분포 근거(역사적 분위수 등)가 없으면 — 특히 N=1·비정상 과정 — 임계값을
   임의로 만들지 말고 **등록 시점에 서술 층으로 강등**한다.
3. **층 라벨** — `판정 트리거` / `서술적 신호` 중 하나를 명시. 서술 층은 판정 경로(정방향·역방향
   모두)에 등장할 수 없다.

관측원만 있고 임계값이 없는 조건은 "라인이 공시돼도 기계 판정 불가"다 (실제 사례: RC-3′, C-④).
관측 실패 시 처리는 fail-closed 로 사전 명시한다 (예: 라인 부재 → `UNVERIFIABLE` 강등).

## P-2. 역방향 산출(reverse-solve) 결과 서술 규약

- 각 역산 축은 **다른 축을 모델값에 고정한 단일-변수 조건부 해**다. 서술은 반드시
  "어느 하나가 **단독으로** 설명하려면 해당 수준 필요(OR)"와 "**축 조합은 비식별**" 프레임만 쓴다.
- 금지: 축 해들을 "동시에 성립", "X **그리고** Y 가 필요" 등 **결합(AND) 명제**로 묶는 서술
  (실제 사례: C-①, "β<1 그리고 20% CAGR 동시 필요").
- **역할 변경 시 전수 치환:** 조건의 강등·승격·정의 교체가 있으면, 정방향 문장뿐 아니라
  **역방향·총칭 문구까지** 전수 grep 으로 치환한다. 금지 총칭: "RC 전부", "모든 RC", "N개 모두"
  — 항상 열거형("RC-1′·RC-2′ 모두")으로 쓴다 (실제 사례: C-⑤; T-3 rev-6 정의 혼재와 동일 패턴 3회 재발).

## P-3. 모델 상대 명제 라벨 규약

- 밸류에이션 결론 문장은 앵커를 **문장 안에** 명시한다: "**{앵커 식별자} 기준** 안전마진 부재"
  (예: "7/10 as-run DCF 기준"). 앵커 없는 절대 명제("안전마진 부재는 확정")는 금지
  (실제 사례: C-②).
- 앵커 식별자는 해시 고정된 산출물(커밋/매니페스트 등재)이어야 하며, "기존 산출 인용이지
  새 공정가치가 아님"을 병기한다 (§2-1 프린트-전 규율).

## P-4. 저술 pre-flight self-lint — 기계 검사와 적대 검증의 경계 (Codex 확정)

검증 발주 전 자체 점검. **자동 실패(FAIL)는 명확한 구조 불변식에만** 적용하고, 자연어 패턴은
**의심 지점 표시(WARN)** 로 제한한다. 자연어를 정규식으로 완전 판정하려 하지 않는다.

**기계화 (도구: `scripts/t3/preflight_lint.py`):**

| # | 검사 | 심각도 |
|---|---|---|
| L-1 | 금지 토큰의 금지 구역 출현 (예: 정량 채점 절의 UNVERIFIABLE 계열) | FAIL |
| L-2 | 총칭 표현: "RC 전부", "모든 RC", "N개 모두" | WARN |
| L-3 | 판정 트리거마다 임계값·관측원·층 라벨 필드 존재 | FAIL |
| L-4 | 단일축 결과 주변의 "동시", "그리고 …필요", "모두 필요" | WARN |
| L-5 | 앵커 상대 결론에 등록된 앵커 식별자 존재 | WARN |
| L-6 | 판정용 RC 목록과 판정 경로 문장의 RC 집합 일치 (서술 층 RC 의 판정 문장 출현) | FAIL |

**Codex 적대적 검증에 남기는 것 (기계화하지 않음):** 다른 이름으로 재유입된 UNVERIFIABLE 정보 ·
임계값의 경제적 정당성 · OR/비식별 서술의 실제 의미 정합성 · 상대 명제의 문맥상 절대화 ·
RC 발화·미발화가 판정을 부당하게 증명하는 구조.

**절차:** 저술 완료 → lint 실행(FAIL 0 필수, WARN 은 항목별로 해소 또는 사유 기록) → 크로스 환경
재생성 게이트(`CONVENTIONS_rev_audit.md` §2) → Codex 핸드오프 발주.
