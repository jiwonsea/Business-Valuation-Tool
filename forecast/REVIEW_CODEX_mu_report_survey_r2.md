## 1. D-2 연락처 분류

**수용.** #8은 한 요소 안에 서로 다른 상태가 섞여 있었다.

- 작성자: `✅ 이미 반영` - rev-3 D9에서 `김지원`으로 확정됐다.
- 연락처: `⛔ 의도적 비공개`를 기본값으로 둔다. 공개 연락처가 없다는 것은 수치 데이터 결손이 아니라 공개 범위 선택이다.

**수정안:** rev-4 분류표의 #8 셀을 `작성자 ✅ / 연락처 ⛔(비공개 기본, Jiwon 결정 시에만 ➕)`로 쓴다. 연락처를 공개한다면 Jiwon이 공개용 주소 또는 URL을 명시적으로 승인한 뒤 별도 설정값과 KO/EN 패리티 게이트를 추가한다. 결정 전에는 개인 연락처를 추정하거나 기존 저장소에서 가져오지 않는다.

## 2. D-4 P/B ed1 배정

**수용.** ed1 배정이 맞다. A-8K 기말 자본총계와 최신 공시 발행주식수는 ed1의 ROE·EV와 같은 공시 입력 계층에서 이미 필요하므로, P/B만 10-K까지 미룰 논리가 약하다.

**수정안:** #20을 `➕ ed1`로 옮기고 §4-5에 다음 보조 행을 추가한다.

`trailing P/B = 기준 주가 / (FY26A-8K 기말 자본총계 / 최신 공시 발행주식수)`

- 목표가·투자의견·RLE P/B에는 연결하지 않는다.
- 기준 주가일, 자본 기준일, 발행주식수 기준일을 캡션에 각각 적는다.
- 자본 또는 주식수 fact가 없으면 `UNAVAILABLE`, 주당장부가치가 비양수면 `N/M`으로 둔다.
- G-3b·G-14·G-15·G-16·G-17·G-20을 적용한다.

## 3. D-5 §2-1 보완 3건 - 피어 설계 개정본

**수용.** 후보 누락, 시장별 종가 시각, 비영문 공시 좌표 계약을 보완한다.

### 3.1 후보 전체에 규칙 적용

아래는 입력 수집 전의 후보 판정이다. 최종 포함은 공시 원본을 핀한 뒤 G-22를 통과해야 확정된다.

| 후보 | 사전 판정 | 최종 포함 조건 |
|---|---|---|
| SK hynix | 전사 비교 후보 | 메모리 매출 과반, 규제 공시 3표·주식수·가격 2경로 재현 |
| SanDisk | 전사 비교 후보 | NAND 중심 매출과 독립 공시 실제치 재현 |
| Kioxia Holdings | 전사 비교 후보 | NAND 중심 매출과 EDINET 공시 실제치 재현 |
| Nanya Technology | 전사 비교 후보 | DRAM 중심 매출과 MOPS 공시 실제치 재현 |
| Samsung Electronics | 운영 지표만 조건부 | 메모리 세그먼트 실제치만 사용. 전사 시가총액을 세그먼트 분모와 결합한 배수는 금지 |

후보마다 `포함 / 제외 / 운영 지표만` 결과와 사유를 manifest 부록 표에 남긴다. 원본 완비 실패는 다른 제공자의 추정치로 채우지 않고 `UNAVAILABLE_FOR_COMPARISON`으로 둔다.

### 3.2 가격 기준일과 시장 시각

1. E2-B 입력 게이트 전에 Nasdaq·KRX·TSE·TWSE별로 2026-10-01 정규장 개장 여부를 공식 거래소 캘린더에서 확인한다.
2. KRX는 공식 규칙상 평일 중 공휴일·거래소 지정 휴장일을 제외하고 거래한다. 2026-10-01은 현재 정규 거래일 후보지만, 거래소가 별도 휴장일을 지정할 수 있으므로 가격 캡처 직전 공식 휴장 공지를 다시 확인한다. [KRX 거래일·휴장 규칙](https://global.krx.co.kr/contents/GLB/06/0602/0602010201/GLB0602010201T1.jsp)
3. 각 가격 fact에 `exchange`, `local_trade_date`, `close_time_local`, `timezone`, `captured_at_kst`, `source_id`를 기록한다.
4. 같은 달력일이라도 KRX·TSE·TWSE 종가가 Nasdaq 종가보다 먼저 확정된다는 점을 캡션에 적는다.
5. 어느 시장이 휴장하면 임의 전일 대체를 금지하고 Jiwon 결정으로 올린다. 승인된 대체일이 없으면 해당 시장가격 기반 배수를 `UNAVAILABLE_FOR_COMPARISON`으로 둔다.

### 3.3 비영문 공시 좌표

공통 `source_id`는 `{regulator, document_id, filing_date, url, local_path, sha256, language}`를 갖는다. 각 fact의 `source_coordinate`는 다음을 필수로 한다.

- DART: 접수번호, 원문 표·주석명, 국문 계정명, 페이지 또는 HTML anchor, 존재하면 XBRL tag와 context.
- EDINET: document ID, 일본어 표·주석명과 계정명, 페이지 또는 HTML anchor, XBRL element와 context.
- MOPS: report/document ID, 중문 표·주석명과 계정명, 페이지 또는 HTML anchor, 존재하면 XBRL tag와 context.

KO/EN 표시명은 파생 라벨일 뿐 lineage 좌표가 아니다. G-14는 원문 계정명과 원문 좌표까지 역추적할 수 있어야 통과한다. 번역이 애매하면 원문명을 보존하고 비교 셀을 `UNAVAILABLE_FOR_COMPARISON`으로 둔다.

## 4. D-6 재고 분할과 ed1 배정

**수용.** 회사 재고와 업계 재고를 분리한다.

- 회사 재고일수: `➕ ed1`
- 업계 재고: `❓`, 합법적·재현 가능한 신규 입력 확보 전에는 미산출

**수정안:** §4-3 비율 행에 FY23A~FY26A-8K 회사 재고일수를 추가한다.

`inventory_days = 평균(기초 재고, 기말 재고) / 매출원가 × (period_weeks × 7)`

- 기초 재고·기말 재고·매출원가는 같은 연결 범위와 회계기준이어야 한다.
- FY26A-8K는 53주를 그대로 반영하고 52주로 환산하지 않는다.
- 기초 재고가 없거나 범위가 다르면 `UNAVAILABLE`; 매출원가가 비양수면 `N/M`.
- RLE는 재고를 모델링하지 않으므로 FY27E·FY28E는 `UNAVAILABLE`.
- G-3·G-14·G-15·G-16·G-17·G-20과 신규 식 위반 주입 테스트를 적용한다.

## 5. D-9 컨센서스 수정 이력

**수용.** #54는 `❓`보다 `⛔ 의도적 제외`가 정확하다.

근거는 원본 시계열 부재보다 상위 결정이다. FQ4 컨센서스는 FROZEN에서 `UNAVAILABLE`, FY27 컨센서스는 G-17b에 따라 `UNAVAILABLE_FOR_COMPARISON`이며 gap·방향 문장을 금지한다. 수정 이력은 이 결정과 충돌한다.

**수정안:** rev-4 분류표에서 #54를 `⛔ - D6·G-17b 충돌`로 바꾸고, 향후 시계열이 확보돼도 Jiwon이 G-17b를 별도로 개정하기 전에는 자동으로 되살리지 않는다.

## 6. D-10 밴드 ed2 범위 선택

**부분 수용 후 정식 일별 밴드안을 선택한다.** ed2 배정과 두 선택지 병기는 수용하지만, 회계연도말 4개 값 표는 역사 비교표이지 팬 또는 밴드 차트가 아니다. 이를 #25·#45 충족으로 세면 명칭과 산출물이 어긋난다.

**수정안:** rev-4의 기본안은 ed2 일별 P/E·P/B 밴드 2개로 둔다.

- 가격: 분할 조정 일별 종가.
- 분모: 각 거래일 현재 시장에 공개돼 있던 최근 TTM GAAP EPS·주당장부가치. 공시일 이전 값을 소급 적용하지 않는다.
- 밴드: 관측 구간의 평균과 표준편차를 사용하되 기간·관측치 수·적자 P/E 제외 규칙을 캡션에 명시한다.
- 적자 또는 비양수 분모는 `N/M`; 임의 보간·윈저라이징·컨센서스 사용 금지.
- G-1·G-3·G-13b·G-14·G-15·G-16·G-17·G-20·G-21 적용.

경량안이 필요하면 `회계연도말 역사 배수 표`라는 별도 대안으로 채택할 수 있으나, 그 경우 #25·#45는 `⛔/미구현`으로 남기고 밴드라고 부르지 않는다.
