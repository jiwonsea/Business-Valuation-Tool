## §3. Codex가 놓친 신규 지적 4건

### 3-1. [P1] **레버 분해는 경로 의존적이다** — Codex는 단일 순차값만 제시했다

Codex는 `+0.0268/+0.1124/−0.0316/−0.0487/+0.0082`를 **정답으로 제시**했으나, 이는 특정 순서(rev→om→below→tax→sh)의 산물이다. 5! = 120 순열 전수:

| 레버 | 순차(고정순서) | 최소 | 최대 | Shapley(120순열 평균) |
|---|---:|---:|---:|---:|
| 매출 | +0.0268 | +0.0257 | +0.0284 | +0.0270 |
| OPM | +0.1124 | +0.1083 | +0.1129 | +0.1106 |
| below-OP | −0.0316 | −0.0317 | −0.0304 | −0.0311 |
| **세율** | **−0.0487** | **−0.0497** | **−0.0455** | **−0.0475** |
| 주식수 | +0.0082 | +0.0077 | +0.0085 | +0.0081 |
| 합계 | +0.0671 | | | +0.0671 |

세율 레버는 순서에 따라 **−0.0455 ~ −0.0497**로 변동한다(폭 0.0042 = base EPS의 0.2%).
→ **제안: 4-lever/5-lever 귀인 규약에 "순서 고정 + 순서 명시" 또는 "Shapley 값 사용"을 명문화한다.** 현재 R6은 "잔차 0"만 요구하고 **경로 의존성은 다루지 않는다** — 잔차 0은 어느 순서에서도 성립하므로 규율이 되지 못한다. **GEV·TSLA·AMD·SK하이닉스 기존 스코어카드 전부에 소급 적용되는 문제다.**

### 3-2. [P1] **R2 "base 0"이 예측 가능한 경상 순이자수익까지 버린다** — 체계적 과소

R2는 "FX·평가손익·지분법·일회성·워런트는 base 0"으로 설계됐다. 그런데 NVDA의 below-OP 블록에는 **현금·채무증권 $50,335M에서 나오는 경상 순이자수익**이 함께 들어 있다:

```
Q1 FY27 순이자 = 이자수익 540 − 이자비용 102 = +438        (연환산 수익률 3.48%)
매출 대비 +0.5367%  →  91,000 적용 시 +488  →  EPS 기여 +$0.0166
```

이것은 **예측 불가 항목이 아니다.** 현금 잔액 × 단기금리로 추정 가능하고 분기마다 안정적이다. R2를 통째로 적용하면 **체계적으로 과소예측**한다.
→ **제안(R2-refined): below-OP를 `경상(순이자·경상 지분법 등, 앵커 허용)`과 `비경상(마크·FX·일회성, base 0 + 밴드)`으로 2분한다.** 이는 Codex Q2가 승인한 marketable/non-marketable 2분할과 **같은 축이 아니다** — 그것은 마크 내부의 분할이고, 이것은 마크 vs 비마크의 분할이다. **두 분할을 합치면 3버킷**: ① 경상 순이자(앵커) ② 시장성 마크(공개주가로 상향추정, 부분관측) ③ 비시장성 마크·일회성(`UNFORECASTABLE`).
→ 후보 v2 `variant_3`에 반영: base EPS `$2.0219 → $2.0385`.

### 3-3. [P1] **계획 §0.1이 스스로 금지한 N=1 추론을 하고 있다** (자기 모순)

rev-2 §10은 "N=1에 유의성 없음"을 근거로 사전등록 3건을 삭제했다. 그런데 같은 문서 §0.1은 한 달치 실현 경로 하나로:
- "**Bear 확률 30%는 과대였을 가능성**" ← 시나리오 지평 전체에 대한 확률을 1개 미실현 관측으로 판단
- "**TTM 앵커는 성장기업에서 체계적으로 낮다 — 재사용 주의**" ← "체계적"을 N=1로 주장

라고 쓴다. Codex는 §1.2에서 CLAUDE.md의 `<5% every quarter`를 한 분기에 적용하는 오류는 잡았으나, **§0.1의 동일 오류는 잡지 못했다.**
→ **rev-3 조치:** 두 문장을 "이번 1회 관측" 서술로 강등하고, 확률·앵커 판정은 **누적 관측이 쌓일 때까지 유보**로 명시.

### 3-4. [P0-보완] **컨센 기준 문제에는 저비용 경험적 검증법이 있다** — Codex의 `BASIS_UNKNOWN` 2분법을 3등급으로 세분할 수 있다

*(⚠️ 초안은 이 절을 "결정적 검증"이라 썼다. **Codex 2차 회신에서 기각** — 데이터 제공자가 actual과 estimate를 항상 동일한 조정 기준으로 저장한다는 보장이 없다. 아래는 강등 반영본이다.)*

Codex는 "소스별 metric definition 없이는 확정 불가 → `BASIS_UNKNOWN` fail-closed"로 판정했다. 옳지만 **경험적 정황 증거를 싸게 얻을 수 있다:**

> **각 애그리게이터가 기록한 과거 3개 분기(Q1 FY27 / Q4 FY26 / Q3 FY26)의 "actual EPS"를 조회한다.** Q1 FY27이 $2.39면 GAAP, $1.87이면 비GAAP을 **시사**한다. 애그리게이터는 surprise 계산을 위해 통상 자기 컨센과 동일 기준의 actual을 저장하기 때문이다. 소요 30분 미만, INFO_CUTOFF_A 이전 정보로 수행 가능.

→ **rev-3 조치 (3등급 fail-closed):** `BASIS_DECLARED`(명시적 metric definition 공표 → 판정 사용) / **`BASIS_VERIFIED_EMPIRICALLY`**(definition 없으나 3분기 일관 일치 → 판정 사용하되 **등급 표기, 완전 확정 아님**) / `BASIS_UNKNOWN`(불일치·조회 불가 → 판정 배제). 등급이 다른 소스는 **분리 보고**하고 min/max 밴드로 섞지 않는다.
