## 1. 배경 — 왜 이게 T3a를 막고 있나

2026Q2 채점에서 매출은 −0.31%로 맞았지만 **드라이버는 틀렸다(상쇄오차)**:

| 드라이버 | 모델 base 가정 | 실측 | 판정 |
|---|---:|---:|---|
| DDR ASP QoQ | +60% (TrendForce 계약가 중앙값) | D램 **+약 30%** | 과대 ~2배 |
| NAND ASP QoQ | +72% | **+50%대 중반** | 과대 |
| D램/낸드 bit QoQ | +5% / +4% | 역산 **+9~16%** | 과소 2~3배 |

여기서 나온 룰 후보: **TrendForce 계약가 지수 ≠ 회사 실현 blended ASP.** LTA 비중이 큰 발행사는 계약가 변동의 일부만 분기 내 실현하며, 2026Q2 실측 pass-through ≈ **0.5**.

**T3a**는 이 pass-through 계수 β를 8~10분기 표본으로 실측 추정하는 작업이다. (사용자가 "0.5 즉시 시딩"을 기각하고 실측 추정을 지시했다.)

**그런데 대조군 정의가 확정되지 않았다.**

## 2. ⑤ — 확정해야 할 단 하나의 질문

> **회사가 발표한 "D램 ASP 전분기 대비 약 30%"는 (a) HBM을 포함한 blended DRAM ASP인가, (b) conventional DRAM 한정인가?**

### 왜 이게 결정적인가
`profiles/sk_hynix.yaml`의 `historical_drivers[q].ddr_asp_qoq`는 주석상 **"일반 DRAM contract price"** = **conventional**이다.

- **(b) conventional로 확정** → 대조군 정합. T3a를 설계대로 바로 진행.
- **(a) blended로 확정** → 직접 비교 **불성립**. `blended = hbm_share × HBM_ASP + (1−hbm_share) × DDR_ASP` 로 분해해 conventional 성분을 뽑아야 하고, **§4-H1의 implied bit 추정(+9~16%)도 전면 재계산** 대상이 된다. HBM ASP는 비공시라 under-identified 문제가 다시 발생한다.
- **확정 불가** → 그 사실 자체가 결론이다. 추정으로 메우지 말 것.

## 3. 조사 경로 (1차 출처 우선)

1. **SK하이닉스 IR 분기 실적발표 자료(PDF)** — 분기별 실적 프레젠테이션에 ASP 문구의 원문과 각주가 있을 가능성이 가장 높다. 과거 분기 자료도 같이 받아 **문구가 일관되게 쓰이는지** 확인할 것(정의는 분기마다 바뀌지 않는다).
2. **컨퍼런스콜 전문** — 디일렉(THE ELEC)이 과거 분기 콜 전문을 게재해 왔다. Q&A에서 애널리스트가 정의를 되묻는 대목이 있으면 결정적이다.
3. **DART 분기·반기보고서** — 사업의 내용에 ASP 관련 기재가 있는지.
4. **⚠️ 국내 언론 기사는 2차 출처다.** "약 30%"는 언론 보도에서 온 값이며, 기사는 정의를 명시하지 않는다. 기사로 정의를 확정했다고 결론짓지 말 것.

**규율**: 확인 가능한 원문 문장을 인용하라. 원문을 못 본 값에 verbatim 인용문을 만들지 말 것(리포 정책 `2a26780`).

## 4. 이 세션이 내놓아야 할 것

### (1) ⑤ 판정
`(a) blended` / `(b) conventional` / `확정 불가` 중 하나 + **근거 원문 인용 + 출처 URL·일자·등급**.

### (2) T3a 착수 시점 권고
아래를 저울질해 **권고와 이유**를 제시할 것. 결정은 사용자가 한다.

**지금 착수 논거**
- ⑤가 (b)로 확정되면 막을 것이 없다.
- 3Q 프린트 전에 forward 벡터를 보정할 시간이 확보된다.

**반기보고서(8월 중순) 대기 논거**
- 반기보고서가 나오면 **한꺼번에** 풀리는 보류 항목: 세전이익·법인세(→T5 유효세율), 영업외손익 분해(→키옥시아 P&L/OCI, T2의 `basis` 재검토), 실제 가중평균 주식수(→주식수 레버 축퇴 해소), 분기 매출총이익(→4레버 축약을 5레버로 복원).
- 개별로 처리하면 같은 파일을 여러 번 건드리게 된다.
- ⑤가 (a) 또는 확정 불가로 나오면 어차피 T3a 설계를 다시 잡아야 한다.

### (3) ⑤가 (a)로 나올 경우의 대응 설계 스케치
`hbm_share` 분해가 필요한데 HBM ASP는 비공시다. 어떤 식별 가정이 필요한지, `historical_drivers` 주석에 이미 쓰인 역산 방식(2026Q1 항목)을 재사용할 수 있는지, 그 경우 **순환 문제**(§9.3-5: 2026Q1은 SK 실측 blended에서 역산된 값이라 표본에서 제외해야 함)가 어디까지 번지는지 검토.
