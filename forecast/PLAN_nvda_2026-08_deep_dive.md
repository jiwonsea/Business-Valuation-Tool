# §2. 정직하게 인정할 것 3가지

### 2-1. 프린트 전 BVT 재평가는 실적 앵커를 못 바꾼다
FY26·TTM(2026-04) 앵커의 모든 실적 입력이 **08-27까지 문자 그대로 동일**. "$207 → $21X"는 **주가 상승의 재기술**이다. → 프린트-전 BVT는 **V-SEG + V2 + V4만**, **공정가치 숫자 미공표**.

### 2-2. 가이던스 완비 기업에서는 **차별적 자유도가 매우 작다** *(rev-3 정정: "0"은 과장 — Codex §1.2)*

NVDA는 매출·GM·opex·세율을 전부 가이던스로 준다. **남은 자유도는 존재한다** — 매출 ±2%, GM ±50bp, opex "approximately", 세율 이산 선택, other income, 주식수. 그러나 그 자유도가 만드는 폭이 작다:

**핵심 관측: 합리적 변형 전체의 EPS 폭이 $2.022~$2.048 = 1.3%인데, 컨센 소스 간 스프레드는 EPS 5.6%·매출 2.7%다.**

### 2-3. GAAP↔비GAAP 브릿지는 **가설**이며, 저비용 경험적 검증법이 있다 *(rev-3a: Codex 조건3 + 세션 §3-4 + Codex 2차 강등)*

**정확한 브릿지 (Codex 제시 원문 조정표, 항등식 확인):**

⚠️ **rev-2의 "비GAAP ≈ GAAP − 세후 지분평가마크(13,290)"는 +517 과대인 근사식**이었다. 정확한 브릿지는 위 조정표다.

**따라서 "컨센서스 = 비GAAP"은 확정이 아니라 가설이다.** 숫자가 가깝다는 것은 기준 증명이 아니다(Codex §1.1).

> **경험적 검증 (Freeze-A 착수 전 필수, 30분 이내, INFO_CUTOFF_A 이전 정보로 수행 가능):**
> **각 애그리게이터가 기록한 과거 3개 분기(Q1 FY27 / Q4 FY26 / Q3 FY26)의 "actual EPS"를 조회한다.** 애그리게이터는 surprise 계산을 위해 통상 자기 컨센과 동일 기준의 actual을 저장한다. Q1 FY27이 **$2.39면 GAAP, $1.87이면 비GAAP**을 시사한다.

⚠️ **"결정적"이 아니다 (Codex 2차 회신 반영).** 데이터 제공자가 actual과 estimate를 **항상 동일한 조정 기준으로 저장한다는 보장이 없다.** 따라서 3분기 일치는 확정이 아니라 **경험적 정황 증거**다.

**3등급 fail-closed 규약:**

| 등급 | 조건 | 사용 |
|---|---|---|
| `BASIS_DECLARED` | 소스가 **명시적 metric definition**을 공표 | HIT/MISS 판정에 사용 |
| **`BASIS_VERIFIED_EMPIRICALLY`** | metric definition 없음, 단 **3분기 actual이 일관되게 한 기준과 일치** | 판정에 사용하되 **등급을 함께 표기**, 완전 확정으로 취급하지 않음 |
| `BASIS_UNKNOWN` | 3분기 중 하나라도 불일치 또는 조회 불가 | **판정에서 배제** |

**서로 다른 기준의 숫자를 min/max 밴드로 섞지 않는다**(Codex P1-2). 등급이 다른 소스는 **분리 보고**한다.
