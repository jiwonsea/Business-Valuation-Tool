## 2. βL 결론 판정

내재 βL 은 T-3의 내재 WACC 로부터 역산된다 (자본구조·Kd 불변 가정):

```
내재 WACC  = 8.5158%      (가격 $223.96 를 설명하는 할인율, rf 와 무관하게 결정됨)
내재 Ke    = (WACC − Kd_at × D%) / E%
           = (8.5158 − 3.9840 × 0.033) / 0.967 = 8.6704%
내재 βL    = (Ke − rf) / ERP = (8.6704 − 4.65) / 4.6 = 0.8740
```

|---|---|---:|
| 4.56% | 7/10 as-run (stale) | 0.8936 |
| **4.65%** | **2026-08-07 Treasury (확정)** | **0.8740** |
| 4.7% | 08/03/2026 (컷오프 이내, 참고) | 0.8631 |
| 4.63% | 08/04/2026 (컷오프 이내, 참고) | 0.8784 |
| 4.63% | 08/05/2026 (컷오프 이내, 참고) | 0.8784 |
| 4.69% | 08/06/2026 (컷오프 이내, 참고) | 0.8653 |

**판정: `βL < 1` 결론 — 유지. 그리고 stale rf 대비 오히려 강화됐다** (0.894 → **0.874**). rf 가 +9bp 올라 βL=1.0 분기점 **4.07%** 에서 더 멀어졌다.

## 3. ⚠️ 미해소 조건 — ERP

**βL 은 rf 와 ERP 에 *동시에* 조건부다.** V2는 rf 축만 해소했다. ERP **4.6%** 는 여전히 **7/10 as-run 가정이며 갱신되지 않았다.**

| βL = 1.0 이 되는 조건 | 임계 | 실제 | 충족? |
|---|---:|---:|:--:|
| ERP=4.6% 고정 시 rf | ≤ 4.07% | 4.65% | ❌ (βL<1) |
| rf=4.65% 고정 시 ERP | ≤ 4.02% | 4.6% | ❌ (βL<1) |

**ERP 민감도 (rf = 4.65% 고정):**

| ERP | 내재 βL | |
|---:|---:|---|
| 3.50% | 1.149 | **β ≥ 1 — 결론 반전** |
| 4.00% | 1.005 | **β ≥ 1 — 결론 반전** |
| 4.02% | 1.000 | **β ≥ 1 — 결론 반전** |
| 4.20% | 0.957 |  |
| 4.60% | 0.874 |  |
| 5.00% | 0.804 |  |
| 5.50% | 0.731 |  |

**rf × ERP 격자:**

| rf \ ERP | 4.00% | 4.60% | 5.00% | 5.50% |
|---:|---:|---:|---:|---:|
| 4.07% ←분기점 | **1.150** | **1.000** | 0.920 | 0.836 |
| 4.56% | **1.028** | 0.894 | 0.822 | 0.747 |
| 4.65% ←**확정** | **1.005** | 0.874 | 0.804 | 0.731 |
| 4.90% | 0.943 | 0.820 | 0.754 | 0.686 |
| 5.00% | 0.918 | 0.798 | 0.734 | 0.667 |

→ **ERP 4.02% 미만이면 βL ≥ 1 로 뒤집힌다.** 7/10 가정 4.6% 는 그보다 높으므로 현재 결론은 유지되나, **ERP 갱신 전까지 βL 수치는 `rf=4.65%·ERP=4.6% 조건부` 표기 없이 인용하지 않는다.**
