## 0. 요약 한 문단

우리는 **매출·EPS 모두 컨센서스를 소폭 상회**하고, **Q3 가이던스는 컨센서스에 딱 맞는 수준($12.5B)에 그친다**고 본다.
매출 $11,650M(컨센 $11.30~11.38B 대비 **+2.4~3.1%**), non-GAAP 희석 EPS $1.66(컨센 $1.61 대비 **+3.4%**), GAAP 희석 EPS $1.075.
근거의 핵심은 하나다 — **AMD는 최근 4분기 연속 자기 가이던스 미드포인트를 +3.85%/+6.28%/+6.98%/+4.62% 상회했고, 컨센서스는 미드포인트 +0.9~1.6%에만 서 있다.**
반대로 **주가 관점의 결론은 부정적으로 기운다**: 옵션 내재 변동폭이 **±12.28%**인데 우리가 보는 Q3 가이던스는 "컨센 상회"가 아니라 "컨센 일치"다. 실적 비트 + 가이던스 인라인은 YTD 두 배 오른 주식에는 실망 조합이다.
가장 큰 미해결 리스크는 **OpenAI·Meta 워런트 각 최대 1.6억주(행사가 $0.01, 총 3.2억주 = 현 희석주식수의 19.4%)의 회계처리**다 — 10-Q에서 확인하지 못했고, **추정으로 메우지 않았다**(§(f) SF3).

### (a-5) 사전등록 A/B — R2(below-OP base 0)의 편향 검정

R2 계약에 따라 base 시나리오의 below-OP를 **0으로 강제**했다. 그러나 실측은 5분기 연속 **양(+)**이다:
`+$19M(25Q1) / +$172M(25Q2) / +$126M(25Q3) / +$322M(25Q4) / +$128M(26Q1)`, 평균 +$153M(매출의 +1.3%).

| | GAAP EPS | non-GAAP EPS |
|---|---:|---:|
| **A. R2 준수 (below-OP = 0)** ← 동결 값 | **$1.075** | **$1.66** |
| B. R2-off (below-OP = 5분기 중앙값 +$128M) | $1.141 | $1.73 |
| 차이 | +$0.066 (+6.1%) | +$0.07 (+4.0%) |

**사전 선언**: 만약 실제 below-OP가 다시 양수로 나오면 A는 EPS를 약 $0.07 과소예측할 것이다. 이는 변명이 아니라 **R2 규칙 자체를 검정하기 위해 의도적으로 감수한 편향**이며, 사후 채점에서 A/B를 함께 채점한다.
참고로 **컨센 $1.61은 B(=$1.73)보다 낮고 A(=$1.66)보다도 낮다** — 즉 컨센의 보수성은 below-OP가 아니라 매출·마진 쪽에 있다.

### (b-3) Data Center 내부 정성 분해 — 서버 CPU vs AI GPU

두 축은 **마진 프로파일이 다르다**(셀사이드 추정: 서버 CPU 마진이 회사 평균 대비 ~10%p 높다). 따라서 DC 매출이 같아도 구성에 따라 GM이 갈린다.

- **서버 CPU (EPYC)** — 경영진이 Q1 콜에서 서버 CPU 매출 **YoY +70% 이상**을 언급. 하이퍼스케일러 인스턴스 확대 + Intel 대비 점유율 이전이 지속. **GM 상방 요인.**
- **AI GPU (Instinct MI3xx)** — Q1 기준 Instinct **YoY +46%**. MI450/Helios는 **Q3 본격 양산**이므로 이번 분기는 아직 MI355X 세대가 주력. **GM 하방 요인**(부품 원가·HBM 비중).
- **믹스 판정**: 이번 분기는 서버 CPU가 상대적으로 더 빠르게 늘어 **GM에 우호적**이라고 본다. 시스템(랙스케일) 매출 인식은 Q3부터이므로 **이번 분기 GM 희석은 제한적**.

## (c) 가이던스 방향 예측 — **이번 발표의 최대 스톡무버**

### (c-1) Q3 2026 가이던스 레인지 예측

| 항목 | **우리 예측 (base)** | bear | bull | Street 벤치마크 |
|---|---|---|---|---|
| **매출 가이던스 미드포인트** | **$12.5B ± $0.3B** | $12.0B | $13.0B | 컨센 Q3 매출 **~$12.5B** (MarketScreener 집계) |
| **non-GAAP 총이익률 가이던스** | **~55.0% (Q2 대비 하향)** | 54.0% | 56.0% | — |
| Q3 컨센 adj EPS | (참고) 우리 모델 base Q3 non-GAAP ≈ $1.85 | | | **$1.89** |

**도출 논리** — AMD의 가이던스 습관을 역산했다. 회사는 직전 분기 actual 대비 다음과 같이 가이던스해 왔다:
`25Q2 actual 7,685 → 25Q3 guide 8.7B (+13.2%)` · `25Q3 actual 9,246 → 25Q4 guide 9.6B (+3.8%)` · `25Q4 actual 10,270 → 26Q1 guide 9.8B (−4.6%, 계절)` · `26Q1 actual 10,253 → 26Q2 guide 11.2B (+9.2%)`.
우리 Q2 base actual $11.65B에 Q3 계절 강세(과거 Q3 슬롯 QoQ 중앙값 +18.6%)와 **H2 클라이언트+게이밍 −20%+ 역풍**을 동시에 얹으면 회사는 **+7~8% 수준의 보수적 가이던스**를 낼 것으로 본다 → **$12.5B**.

**GM을 하향 가이던스한다고 보는 이유**: Helios/MI450 시스템 매출이 Q3부터 인식되며 **부품 대비 시스템은 GM을 희석**한다. CFO가 이미 "near-term margin pressure"를 예고했다. Q2 56% → Q3 55%가 자연스러운 경로다.

### (c-2) 방향 판정과 주가 함의 — **이 문서의 핵심 주장**

> **판정: 매출 가이던스 "유지(컨센 일치)" · GM 가이던스 "하향".**

옵션 시장은 발표 후 **±12.28%** 움직임을 가격에 반영하고 있다(주가는 YTD 약 2배). 이 셋업에서:

- **Q2 비트(우리 예측: 매출 +2.4~3.1%, EPS +3.4%)는 이미 가격에 있다.** "AMD는 가이던스를 상회한다"는 것은 시장이 아는 사실이다.
- **주가를 올리려면 Q3 가이던스가 컨센($12.5B)을 *편안히* 상회해야 한다.** 우리는 그렇게 보지 않는다.
- **GM 가이던스 하향(56%→55%)이 겹치면 부정적 반응 확률이 높다.**

→ **비대칭 결론: Q2 숫자는 이기고 주가는 빠질 가능성이 우세하다.** 이는 EPS 예측과 독립적으로 채점 가능한 별도 주장으로 사전등록한다.

*민감도: non-GAAP GM 100bp = non-GAAP EPS 약 $0.061 = GAAP EPS 약 $0.060.*

### SF2 — below-OP 블록 + 세율 (R2/R3)
투자평가손익·이자·환·일회성·**중단영업**(ZT Manufacturing 매각, 10-Q Note 5: 25Q4 −$109M / 26Q1 +$11M).

*민감도: 세율 ±400bp = GAAP EPS 약 ∓$0.051.*

### SF3 — 워런트 / 주식수 희석 (**미해결 — 추정으로 메우지 않음**)
**확인된 것**: OpenAI와 Meta가 **각각 최대 1.6억주**의 AMD 워런트를 보유(행사가 **$0.01**, 성과·배치 마일스톤 연동)로 보도됐다. 합계 **3.2억주 = 현 희석주식수 1,650M의 19.4%**.

- ①이면 **매출 레버 직격** — 우리 매출 예측이 구조적으로 과대.
- ③(+희석)이면 **주식수 레버 직격** — 우리 1,658M 가정이 과소.
**추정으로 메우지 않고 "미확인"으로 두고 밴드에 반영했다.** 해소 경로는 (e)-2 또는 발표 후 10-Q.

## 8. 백테스트 / 스킬 지표 (오프라인, 1-step, seasonally-aware)

| 구간 | N | 매출 MAPE / bias | EPS MAPE / bias | MASE (매출/EPS) | Theil U2 (매출/EPS) |
|---|---:|---|---|---|---|
| **Post-break (headline, 2025Q3~)** | 3 | 1.1% / −0.7% | 12.8% / **−12.8%** | 0.125 / **0.688** | 0.106 / **0.647** |
| Full window | 8 | 1.2% / +0.0% | 38.0% / −4.0% | 0.150 / **0.994** | 0.126 / **1.169** ⚠ |
| Pre-break | 5 | 1.3% / +0.5% | 53.1% / +1.3% | 0.174 / **1.166** ⚠ | 0.156 / **1.354** ⚠ |

**정직성 고지 (DELTA §2.1 · §"no silent caps")**
1. **매출 MAPE 1.1%는 스킬이 아니라 in-sample 적합이다.** `backtest_methodology`의 캘린더-슬롯 벡터를 바로 그 9개 분기의 중앙값으로 산출했으므로, 이 수치를 out-of-sample 예측력으로 읽으면 안 된다. **비교 가능한 유일한 숫자는 MASE/Theil**(RW 대비)이다.
2. **full-window·pre-break EPS는 나이브 RW보다 나쁘다**(Theil 1.169 / 1.354). 원인은 2025Q2(MI308 충당으로 GAAP OP 음수)와 2024년 저마진 구간을 고정 op_margin 슬롯이 추적하지 못하기 때문이다. → 헤더 `LOW_SKILL: PARTIAL`.
3. **post-break N=3은 통계적으로 무의미한 표본이다.** 방향성 참고 이상으로 쓰지 않는다.
4. **Yahoo 컨센서스 조인 N=0** — 샌드박스에서 라이브 컨센 취득 불가. §(d)의 컨센은 **웹 리서치로 수집한 provider 값**이며 엔진의 consensus 레이어를 거치지 않았다.

**forward 손계산 대조 (DELTA §R4 필수 절차)**
`rev × (1+g)` 수동 검증: bear 10,253 × 1.0729 = **11,000.4** · base 10,253 × 1.1363 = **11,650.5** · bull 10,253 × 1.1801 = **12,099.6** · 확률가중 0.25/0.50/0.25 = **11,600.3** — **엔진 출력(11,000 / 11,650 / 12,100 / 11,600)과 일치 ✅**

**FY 표기 주의**: `reports/amd_generic_forecast.md`의 "FY2026 EPS"는 **전망 구간에 포함된 2026Q2~Q4 3개 분기 합**(base $3.54)이며 2026Q1 실적($0.84)을 포함하지 않는다. FY2026 전체 GAAP EPS는 base 기준 $0.84 + $3.54 = **$4.38**. "FY2027"은 2027Q1 한 분기(base $1.16)뿐이다.
