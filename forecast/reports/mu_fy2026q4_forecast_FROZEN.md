### (b-2) GM → `op_margin` 번역 (스키마 한계)

`GenericProfile`은 `extra="forbid"`이고 GM 필드가 없다. GM은 `op_margin`으로 번역해 넣었다:

$$\text{op\_margin} = \text{GM} - \frac{\text{GAAP opex}}{\text{매출}}$$

| | GM | opex / 매출 | **op_margin** |
|---|--:|--:|--:|
| bear | 85.0% | 1,860 / 49,000 = 3.80% | **81.20%** |
| base | 86.0% | 1,860 / 52,860 = 3.52% | **82.48%** |
| bull | 87.0% | 1,860 / 58,223 = 3.19% | **83.81%** |
| (참고) 가이던스 중간 | 86.0% | 1,860 / 50,000 = 3.72% | 82.28% |

- opex는 **달러 고정**(가이던스 약 $1.86B GAAP / $1.65B 비GAAP)이고 매출이 달라지므로 시나리오별 op_margin이 다르다. 번역은 FQ4에서만 정확하다 — 엔진은 op_margin을 **비율로 고정**하므로 매출이 움직여도 opex가 달러로 고정된다는 구조를 재현하지 못한다(매출 1% 변화 시 엔진 EPS +$0.33 vs 달러 고정 opex +$0.34, 차이 무시 가능).
- GM 경로와 opex 경로(FY27 [1,900, 1,950, 2,150])는 프로파일 `notes`에만 있다. 기계 검증 필드가 아니다.
- FY27 opex: 준비문 *"increase by approximately $1 billion in fiscal 2027 … weighted to second half."* → 경로는 하반기 가중으로 반영.

## §(c) FY2027 Q1 가이던스 예측 · 14주 → 13주 복귀

### (c-1) 🔴 캘린더 효과를 먼저 떼어낸다

FY2027 Q1(2026-09-04 ~ 2026-12-03 예상)은 **13주**다. FQ4(14주) 대비 **표면 QoQ에 −7.1%(= 13/14 − 1)가 순수 캘린더로 들어간다.** 따라서 FQ1 가이던스가 FQ4 실적보다 낮게 나와도 그 자체로 피크아웃 신호가 **아니다**. 판정은 **주당 기준**으로 한다:

$$g_{\text{주당}} = \frac{G_{FQ1}/13}{A_{FQ4}/14} - 1$$

(가이던스 중간값 $G$, FQ4 실적 $A$ — 둘 다 프린트 당일 공개되므로 사후 채점 가능)

### (c-2) 예측 — 가이던스 중간값과 레인지

도출(서술 산술, 프로파일 입력 아님): 프로파일 FY27 Q1 **실적 경로**를 FQ4 앵커와 같은 규칙(실적 = 가이던스 × (1 + 사후 break 중앙값 상회 5.72%))의 역으로 되돌렸다.

| | bear | **base** | bull |
|---|--:|--:|--:|
| 프로파일 FY27 Q1 실적 경로 (13w) | 41,860 | **51,539** | 60,552 |
| 주당 성장 `g_week` (notes `WEEK_NORM`) | −8% | **+5%** | +12% |
| **예측 가이던스 중간값** (÷ 1.0572) | ≈ 39,600 | **≈ 48,750** | ≈ 57,300 |
| 표면 QoQ (vs 해당 시나리오 FQ4) | −19.2% | **−7.8%** | −1.6% |
| **주당 QoQ** | −13.0% | **−0.7%** | +5.9% |

- **base 예측: FQ1 FY27 매출 가이던스 $48.75B ± 약 $1.0~1.25B** (회사 관행 반폭 ±2.0~2.5%). 표면상 FQ4 대비 약 −8% "하락"이지만 그중 **−7.1pt가 캘린더**이고 주당 기준으로는 **보합(−0.7%)**이다.

- GAAP EPS 가이던스 중간값(서술 산술): 48,750 × 86% − opex 1,900 → 영업이익 40,025, below-OP −111, ETR 13.86% → **≈ $29.90**. 비GAAP ≈ $30.2(+$0.27 가정, FY27 SBC 미상).
- **방향 판정(사전등록)**: 무차이 밴드를 **주당 ±2.0%**(= 회사 FQ4 가이던스 반폭 $1.0B/$50.0B)로 **먼저 선언**한다. 주당 ≥ +2.0% `GROWTH` / ±2.0% 이내 `FLAT` / ≤ −2.0% `DECLINE`.
  → **예측: `FLAT`**(base, 확률 0.50) · `DECLINE` 쪽 위험 0.20(bear) · `GROWTH` 0.30(bull). 확신도 **중-하**.

### (f-4) SF8 — R1/naive 검증 게이트 (PLAN §2-1-a RC-1~RC-4)

우선 outcome은 **EPS가 아니라 연결 GAAP 영업이익**이다.

| RC | 고정 비교값 (FQ4, 동결 시점) | 규칙 | 층 |
|---|---|---|---|
| **RC-1** paired R1 우위 | **A** = base 영업이익 **43,599** (최신 level) · **B** = `backtest_methodology` 1-step: 매출 41,456 × 1.1772 = 48,802, 영업이익 × 24.14% = **11,781** (과거 중앙값 level) | \|OP_A − actual\| − \|OP_B − actual\| ≥ 0 → **A 우위 실패**(동률 포함) | 판정 |
| **RC-2** naive 우위 | **C** = 직전 실적(RW): 영업이익 **33,318** · 매출 41,456 · GAAP EPS 24.67 | \|A − actual\| ÷ \|C − actual\| ≥ 1 → naive 미극복. 분모 0이면 원 손실 비교, 누락이면 `UNVERIFIABLE` | 판정 |
| **RC-3** 재검토 | base 매출·GAAP EPS | 매출 APE > **10%** 또는 EPS APE > **25%** → 가정 재검토 | 판정 (재검토 트리거) |
| **RC-4** 사이클 일반화 | 발행사 PR series | 임계값 미설정 | **서술** |
| **밴드 커버리지** | 매출 [49,000, 58,223] · GAAP EPS [29.33, 36.66] | 밖이면 **밴드 실패** 기록(특히 < bear = 가이던스 하단 미달) | 판정 |

- RC-1 한 분기 실패는 **보편 R1 실패의 통계적 입증이 아니다.** A가 실패해도 동결을 유지하고 사후 채점한다.
- RC-2의 C는 14주를 모른다(13주 실적). 이는 RW의 정의상 한계이며 보정하지 않는다.

**스킬 게이트 — `NO_OOS_SKILL_EVIDENCE`** (복수 태그: `IN_SAMPLE_ONLY`, `EPS_WORSE_THAN_RW`)

| 창 (in-sample) | N | 매출 MAPE | RW 매출 MAPE | 매출 MASE | 매출 U2 | EPS MAPE | RW EPS MAPE | EPS MASE | EPS U2 |
|---|--:|--:|--:|--:|--:|--:|--:|--:|--:|
| 전체 | 10 | 11.05% | 19.82% | 0.652 | 0.749 | 74.5% | 74.0% | **1.264** | **1.455** |
| 최근 8 | 8 | — | 20.60% | 0.690 | 0.751 | — | 42.7% | **1.324** | **1.465** |

- 🔴 **이 백테스트는 스킬 근거가 아니다.** `backtest_methodology`(슬롯 성장·op_margin·세율·below-OP 중앙값)는 **채점 대상인 같은 10분기에서 적합**했다. 매출 MASE < 1, U2 < 1은 in-sample 정합성이지 표본 외 성능이 아니다. EPS는 in-sample에서도 MASE·U2 > 1 — RW보다 나쁘다.
- 스킬 주장 조건(MASE < 1 **그리고** U2 < 1, 표본 외)은 **충족되지 않았다**. 방향 적중률(0.9)은 스킬 근거로 쓰지 않는다.
- SNDK 교훈을 상속한다: *백테스트와 동결 예측(가이던스 기반 나우캐스트)은 같은 것을 재지 않는다.* MU에서는 한 단계 더 약하다 — 백테스트가 사후지식 없는 앵커도 아닌 in-sample 적합이다. **표본 1(이번 분기)로 스킬을 갱신하지 않는다.**
- 컨센서스 스킬(SF8 역사): `UNAVAILABLE` — 라벨 계약 불일치로 자동 경로 거부.
