## 2. POSITION A — Claude 주장: **조건부 채택**

### A-1. 채택 근거

1. **사용자 스크린 조건을 정확히 만족.** 코스닥 / 중소형(3,308억) / 반도체 부품 / 3개월 내 투자의견 0건.
2. **영업 레벨이 예외적으로 안정.** 5개 분기 OP마진 14.84~18.27%, **표준편차 ~1.3pp**. GEV(9.2% 가정 vs 5.88% 실적)·TSLA(6% 가정 vs 1.4%)에서 리졸버 R2를 파괴한 램프/웨지가 **여기엔 없다**. R2(최근 4Q 가중 연결 GAAP OP 마진 앵커)가 처음으로 순풍을 받는 케이스.
3. **매출도 순한 편.** QoQ +6.5% / +12.5% / −5.1% / +4.4%. 단일 제품·단일 전방이라 드라이버가 하나(삼성·SK 장비 발주)로 압축된다.
4. **전방 신호가 이미 공개돼 있다.** SK하이닉스·삼성전자 2026Q2 실적이 메카로 프린트(8/14)보다 **선행**한다. 전방→후방 리드-래그를 실시간 검증할 수 있는 드문 배치.
5. **동결 창 확보.** T-72h = 8/11, 여유 11일. 데이터 경로(WebFetch→DART)도 실측 완료.
6. **리서치 알파의 원천이 명확.** 커버리지 공백 + 외국인 2.29% + 성장률 +50% → +19% 급감속 구간. 컨센서스가 없으니 "컨센 추종" 오염 자체가 불가능하다(오토파일럿 하드룰과 우연히 합치).

### A-3. 채택 조건 (이게 협상 대상)

1. **채점축을 매출·영업이익으로 한정.** EPS/순이익은 **밴드만 제시하고 점수화하지 않는다(NO-SCORE 선언).** 사후에 "밴드가 포함했는가"만 커버리지로 기록.
2. **below-OP·세율은 시나리오가 아니라 명시적 무지 선언.** R4 base 0 유지 + 밴드는 15Q 실측 분위수(±51% 수준)를 그대로 노출. 좁히려는 시도 금지.
3. **FY25 tie-out 갭 +2.50억을 먼저 해소.** 중단영업 항목인지 확인 전에는 actuals 빌드 금지(`build_generic_actuals.py` 무결성 게이트).
4. **backtest는 2022Q4~ 로 하드 컷.** 전구체 시대 분기 유입 시 REFUSE.
5. **캘린더 앵커 = 법정 마감일** (`calendar/earnings_calendar.yaml`에 `anchor: statutory_deadline` 필드 신설).
6. **BVT 쪽은 3중 앵커 중 forward 컨센 결손** → FY확정/TTM 2중 앵커 + 하방(distress) 강조로 축소 운용.

## 3. POSITION B — Codex가 방어할 반대 주장: **월덱스(101160)로 교체**

Codex는 아래를 **최대한 강하게** 밀어붙일 것. Claude 결론을 추인하는 답변은 이 문서의 목적이 아니다.

**B-1. 메카로는 밸류에이션이 이미 비싸다.** PER 26.2 / PBR 1.58인데 성장률은 +50% → +19%로 꺾였다. 커버리지 공백 = 정보 비효율이라는 전제는, 시장이 이미 성장주 멀티플을 부여한 종목에서는 성립하지 않는다. 월덱스는 **PER 11.6 / PBR 1.37**로 같은 섹터·같은 무커버리지 조건에서 절반 이하 멀티플이다. "커버리지 공백에서 알파를 찾는다"는 목적에 더 정합적이다.

**B-2. 외국인 2.29%는 정보 비효율이 아니라 유동성 함정일 수 있다.** 유동주식 45.9%, 시총 3,308억. 리서치 결론이 나와도 실행 가능한 사이즈인가? 월덱스는 유동비율 64.4% / 외국인 16.0%로 가격 발견이 더 작동한다.

**B-3. below-OP 문제는 "조건부 채택"으로 봉합되지 않는다.** EPS를 채점에서 빼면 EFE가 채점하는 건 매출과 OP뿐인데, 그 둘은 이 종목에서 **너무 순해서 RW 대비 skill이 나오지 않는다**(QoQ 변동폭이 작고 추세적). 즉 A-1의 근거 2·3(안정성)과 채점 가치는 **상충**한다. 맞히기 쉬운 것만 채점하면 방법론 검증이 안 된다.

**B-4. 15Q 표본으로 R7 밴드를 만들면 밴드 자체가 통계적 허구다.** 분위수 추정에 15개 관측은 부족하고, 그중 1개(2025Q4)가 극단값이라 밴드가 그 한 점에 끌려간다.

**B-5. 지금은 NVDA 파일럿(8/24 동결) 직전이다.** `efe-autopilot-design` 메모리 기준 P0 블로커(local ahead 26 커밋, PAT 미발급, P1 미구현)가 미해결이다. 신규 국가·신규 데이터경로·신규 캘린더 규약을 요구하는 종목을 **지금** 넣는 것은 범위 규율 위반이다.
