## §7. 4-lever generic 귀인 — GAAP EPS

### 7.1 경로와 결과

경로는 **매출 → 영업이익률 → OP→NI 전환 → 주식수**로 고정했다. 시작점은 동결 base의 미반올림 EPS `37,452/1,150 = $32.56696`, 끝점은 실제 `37,701/1,147 = $32.86922`다. OP→NI 전환율은 각각 `NI/OP`로 정의해 영업외·세금·지분법을 모두 포함한다.

| 레버 | 적용식 | EPS 기여 |
|---|---|---:|
| 매출 | 실제 매출 54,229로 교체, base OP margin·전환율·주식수 유지 | **+$0.843** |
| 영업이익률 | base 82.480% → 실제 80.678%, 실제 매출 유지 | **−$0.730** |
| OP→NI 전환 | base 85.901% → 실제 86.172%, 실제 OP 유지 | **+$0.103** |
| 주식수 | 1,150M → 1,147M, 실제 NI 유지 | **+$0.086** |
| **합계** | 32.56696 → 32.86922 | **+$0.302** |

표시 EPS 기준 actual−base $0.30과 일치한다. 잔차 0은 대수적 보장이며 정확성 근거가 아니다. 정확성 근거는 §1 원문 항등식이다.

### 7.2 OP→NI 하위 분해

actual OP에서 base 전환 구조를 실제 구조로 바꾸는 순서로 분해했다.

| 하위 레버 | EPS 기여 |
